# NauticNav

Moderne marine Navigations-App für Android/OnePlus im Hochformat.

Enthalten: Distanz in sm, SOG aktuell + Mittelwert der letzten 0,5 sm, COG aktuell + Mittelwert, Uhrzeit, Fahrtzeit, Position, GPS-Satelliten/Genauigkeit/3D-Fix, Tag/Nacht, dimmbare Nachtansicht und eine zentrale Reset-Taste.

## Build
Der GitHub-Workflow unter `.github/workflows/build-apk.yml` erzeugt bei Push auf `main` eine installierbare Debug-APK und lädt sie als GitHub Actions Artefakt hoch.
